# Lucky7

Java-peli, jossa arvotaan kolme numeroa väliltä 1–10. Kierros maksaa yhden euron. Yhdellä seiskalla voittaa 3 euroa, kahdella 5 euroa ja kolmella 7 euroa.

Käynnistys projektikansiossa:

```text
javac -encoding UTF-8 -d bin src/Lucky7.java
java -cp bin Lucky7
```

Anna aluksi rahamäärä kokonaislukuna. Kierroksen jälkeen Enter jatkaa ja `e` lopettaa. Peli loppuu myös, jos rahat loppuvat.
